# V2.0 — relatório do renderer

Núcleo experimental 2D de laboratório. Sem fill, sem FaceMesh, sem integração de produto. Este documento fecha a Sprint V2.0 para revisão; a V2.1 não foi iniciada.

## Convenção matemática

Remap **backward**:

```
src = dest − displacement
```

Para o pixel destino inteiro `(x, y)`:

```
srcX = x − field.dx[y * width + x]
srcY = y − field.dy[y * width + x]
```

O campo é **por pixel** (`DisplacementField`); o renderer não interpola o campo. A imagem, quando a origem é válida, é amostrada por **bilinear**.

Translação inteira de laboratório (`DisplacementField.translation`, só testes): o destino `(x, y)` com `d = (3, 0)` lê a fonte `(x − 3, y)` no interior.

## Coverage e invalidSource

Um byte por pixel destino, comprimento `width * height`.

| Estado | Condição | `rgba` | `coverage` | `invalidSource` |
| --- | --- | --- | --- | --- |
| Origem válida | `src` no rect fechado `[0, width−1] × [0, height−1]` | amostra bilinear | 255 | 0 |
| Origem inválida | `src` fora desse rect | **destino original preservado** (cópia da fonte no destino) | 0 | 1 |
| Campo nulo e origem válida | `d = 0` e `src = dest` dentro do rect | identidade | 255 | 0 |

Não há clamp de coordenada OOB para a borda da fonte. Não há Telea, hole-fill nem `ContourMasks`.

## Bordas

- Coordenada OOB (`srcX < 0`, `srcY < 0`, `srcX > width−1` ou `srcY > height−1`): origem inválida; não se amostra; o pixel de destino não é substituído pelo pixel da borda da fonte.
- Última coluna / última linha **dentro** do rect (p.ex. campo zero em `(width−1, y)`): origem válida. Bilinear **degenerado** (taps repetidos) para não exigir um pixel à direita/abaixo que não existe. Isto não é clamp de origem fora da imagem.
- Campo zero: RGBA idêntico à fonte; `coverage` 255 em todos os pixéis, incluindo o bordo.

Prova anti-clamp (teste): translação `dx = 3`; destinos `x ∈ {0,1,2}` são inválidos; em `x = 1` o RGBA preservado é o da fonte em `x = 1`, distinto da borda `x = 0` que um clamp escreveria.

## Isolamento

Confirmado: **não há dependência da V1 de warp, FaceMesh, UI de produto nem Controller.**

O renderer (`backward_bilinear_warp.dart`) importa só `dart:typed_data` e `displacement_field.dart`. Não importa `extended_roi`, `WarpField`, `WarpCpuRemap`, `BackwardWarp2D`, `PassWarp`, `FaceMeshResult`, `beauty_engine_controller`, `package:flutter/`, Telea, inpaint nem jaw.

`DisplacementField` importa `dart:typed_data` e `dart:ui show Offset` (só `displacementAt`; sem widgets). O renderer **não** usa `Offset`. `translation()` permanece exclusivo de testes sintéticos.

Testes de isolamento leem o código-fonte e falham se esses imports existirem.
