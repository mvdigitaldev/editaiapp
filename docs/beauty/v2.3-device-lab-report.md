# V2.3 — relatório do Device Lab

Device Lab, não integração de produto. A V1 continua a pintar o preview. Sem fill, sem Telea, sem parser, sem rollout, sem troca de `PassWarp`.

Este documento fecha a Sprint V2.3. **Não há sprint seguinte neste plano.**

## O que foi feito

- Flag `FacialWarpV2Config.facialWarpCoreV2Lab = false` por omissão (também `--dart-define=FACIAL_WARP_V2_LAB=true`).
- Dump paths **independentes** de `ExtendedRoiDumpPaths` / `FaceWarpV3Config`.
- Runner `FacialWarpV2DeviceLab`: JawField + renderer → `v2Raw` só quando a flag está on, a foto é p01/p05/p12 (tamanho nativo) e o frame é **jaw-only**.
- Gancho paralelo **depois** do frame V1, na foto full-res (`_source`). Não substitui o `TextureHandle`.

## Flag

| Estado | Preview V1 | Dump V2 |
| --- | --- | --- |
| `facialWarpCoreV2Lab = false` (default) | inalterado; nenhum código V2 no caminho quente além de um `if` | não escreve |
| `true` + jaw-only + p01/p05/p12 | **byte-a-byte o mesmo RGBA V1** | escreve `v2Raw` e mapas |
| `true` + chin / v_face / face_slim / narrow_face | V1 inalterada | **não corre** (`not_jaw_only`) |
| `true` + outra foto | V1 inalterada | **não corre** (`not_approved_photo`) |

Checkbox debug **V2 Device Lab** (não é toggle de produto). Arranque: desligado.

Protocolo no dispositivo físico (full restart; hot reload não chega):

1. Abrir o editor com p01 / p05 / p12 **à resolução nativa** (695×1024 / 740×740 / 960×1440).
2. `jaw` 0 / 25 / 50; chin, v_face, face_slim, narrow_face a zero.
3. Ligar **V2 Device Lab**. Um frame.
4. Log: `V2 Device Lab: dumped p01 t=0.5 dir=...`
5. Preview continua a ser V1.

## Desvios

- O plano nomeava `enabled`; o pedido desta sprint fixou `facialWarpCoreV2Lab`.
- Gancho no editor, não em `PassWarp` nem no controller — menor risco de ramo de render.
- Dump usa `_source` full-res porque o preview é downscaled e não coincidiria com os tamanhos aprovados.

## Riscos

- O checkbox debug pode ser lido como feature de produto. Default continua false.
- O primeiro dump full-res pode atrasar um frame; o preview V1 já foi apresentado.
- Foto aprovada reencodada com outro tamanho não dispara o lab.

## Rollback

`facialWarpCoreV2Lab = false`. A V1 nunca foi desligada.
